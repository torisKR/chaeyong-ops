# 채용옵스 brand assets

Funnel + checklist mark for the Korean fork, with a **KR** accent. Raster hero art lives next to SVG fallbacks.

| File | Use |
|------|-----|
| `icon.png` | App icon (README logo near title) |
| `banner.png` | Hero banner (README, under the title/badges) |
| `logo.svg` / `icon.svg` | Vector fallback of the mark |
| `favicon.svg` | Tab / shortcut icon |
| `wordmark-light.svg` | Vector wordmark (light background) |
| `wordmark-dark.svg` | Vector wordmark (dark background) |

These are original **채용옵스 (Chaeyong Ops)** assets. They are not the upstream `career-ops` logo. See [NOTICE.md](../NOTICE.md) and the upstream [trademark policy](https://github.com/career-ops-hq/career-ops/blob/main/TRADEMARK.md).
