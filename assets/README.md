# 채용옵스 brand assets

Simple geometric mark for the Korean fork: a document (JD / CV) feeding a funnel (pipeline filter), with a **KR** accent.

| File | Use |
|------|-----|
| `logo.svg` / `icon.svg` | App mark (README hero, 96×96) |
| `icon.png` / `banner.png` | Optional raster hero (use in README when present) |
| `favicon.svg` | Tab / shortcut icon |
| `wordmark-light.svg` | README wordmark (light background) |
| `wordmark-dark.svg` | README wordmark (dark background) |

These are original SVG placeholders for **채용옵스 (Chaeyong Ops)**. They are not the upstream `career-ops` logo. See [NOTICE.md](../NOTICE.md) and the upstream [trademark policy](https://github.com/career-ops-hq/career-ops/blob/main/TRADEMARK.md).
